# Expression name table for the MiniDayZ+1.2 export.

# Format:   <S|O|B> <plugin> <index> <Name> [behavior]
#   S = system expression, O = object expression, B = behavior expression.
#   plugin -1 is the System object, 18 is Sprite.
#
# Expressions carry no index at runtime -- Construct 2 binds the function to
# the node at load and discards it -- so these were recovered by matching ACEs
# by SID and then pairing expression trees within each matched ACE. That
# pairing validates itself against the node types both sides report: 106683
# nodes paired with zero type mismatches and no key resolving to more than one
# implementation. See docs/expressions.md.
#
# Names were read off the implementations. Many are pinned exactly because
# Closure does not rename properties that collide with externs, so round,
# ceil, floor, abs, sqrt, find, left, right, replace, trim and Text survive
# minification as literal property names in c2runtime.js.
#
